## 3. PRODUK & KENDARAAN OPERASIONAL: DX PLATFORM

> **"KODE BERDAULAT DI ATAS BARE-METAL."**

- **Definisi Produk:** **DX (Developer eXperience)** adalah perwujudan fisik instrumen kerja developer.
- **Riot Anarchy / Anti-Slop:** Menghabisi 100% bloatware korporat, ketergantungan internet eksternal, dan proses perizinan birokratis.
- **Arsitektur Teknis Inti:**
  1. **Native Git Smart HTTP (`:3200`):** Subprocess langsung `git-http-backend` di atas runtime Bun. Bare repository tersimpan langsung di storage lokal.
  2. **PocketBase SQLite BaaS (`:8091`):** Control plane single-binary Go/SQLite untuk autentikasi user, hashing token PAT berentropi tinggi, dan audit record.
  3. **Cockpit UI Next.js 16 (`:3000`):** Antarmuka neobrutalisme ergonomis tanpa ketergantungan cloud pihak ketiga.
  4. **Anarchy Weapons Lab:**
     - *Airdrop Git:* P2P Mesh sync laptop-ke-laptop via broadcast mDNS tanpa router/internet.
     - *Dead Man's Nuke:* Panic protocol penghancur memori & keys menjadi cryptographic white noise saat inspeksi paksa.
     - *Commit Stream Escrow:* Smart contract berbasis git trailer untuk pencairan bounty kontributor otomatis.
     - *Keystroke Biometric Cadence:* Verifikasi ritme ketikan jari manusia asli untuk memblokir AI scraper spam.
